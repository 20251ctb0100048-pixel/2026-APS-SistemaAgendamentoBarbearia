# 4.2.1 — Levantamento de Requisitos

## 1. Como os requisitos foram levantados

Os requisitos foram definidos com base no que foi planejado para o Sistema de Agendamento para Barbearia e nas funcionalidades que o sistema precisa ter.

Não foi registrada uma entrevista com o cliente, então não foram criadas falas que não aconteceram.

## 2. Da fala à necessidade

Como não temos as falas do cliente registradas, foram consideradas as necessidades identificadas no projeto.

| Fala do cliente | Necessidade                    |
| --------------- | ------------------------------ |
| Não registrada  | Cadastrar clientes             |
| Não registrada  | Cadastrar barbeiros e serviços |
| Não registrada  | Criar agendamentos             |
| Não registrada  | Consultar agendamentos         |
| Não registrada  | Cancelar agendamentos          |

### Perguntas para o cliente

1. Quais informações devem ser cadastradas para cada cliente?
2. Quais informações devem ser cadastradas para cada barbeiro?
3. Quais serviços a barbearia oferece?
4. Quem poderá criar, consultar e cancelar agendamentos?
5. Existem regras para os horários e para o cancelamento dos agendamentos?

## 3. Histórias de usuário

### HU01 — Cadastrar cliente

Como atendente, quero cadastrar clientes para manter os dados deles no sistema.

**Veio de:** necessidade de cadastrar clientes.

### HU02 — Cadastrar barbeiro e serviço

Como atendente, quero cadastrar barbeiros e serviços para usar essas informações nos agendamentos.

**Veio de:** necessidade de cadastrar barbeiros e serviços.

### HU03 — Criar agendamento

Como atendente, quero criar agendamentos para registrar os horários dos clientes.

**Veio de:** necessidade de criar agendamentos.

### HU04 — Consultar agendamentos

Como atendente ou barbeiro, quero consultar os agendamentos para verificar os horários marcados.

**Veio de:** necessidade de consultar agendamentos.

### HU05 — Cancelar agendamento

Como atendente, quero cancelar agendamentos para manter a agenda atualizada.

**Veio de:** necessidade de cancelar agendamentos.

## 4. Requisitos funcionais

| ID   | Requisito                              | Veio de |
| ---- | -------------------------------------- | ------- |
| RF01 | O sistema deve cadastrar clientes.     | HU01    |
| RF02 | O sistema deve cadastrar barbeiros.    | HU02    |
| RF03 | O sistema deve cadastrar serviços.     | HU02    |
| RF04 | O sistema deve criar agendamentos.     | HU03    |
| RF05 | O sistema deve consultar agendamentos. | HU04    |
| RF06 | O sistema deve cancelar agendamentos.  | HU05    |

## 5. Requisitos não funcionais

| ID    | Requisito                                                                             | Categoria   |
| ----- | ------------------------------------------------------------------------------------- | ----------- |
| RNF01 | O sistema deve apresentar as informações de forma simples e organizada.               | Usabilidade |
| RNF02 | O sistema deve permitir que cada tipo de usuário tenha acesso às funções necessárias. | Acesso      |
| RNF03 | O sistema deve funcionar em computador com acesso ao sistema.                         | Dispositivo |

## 6. Conferência com a 4.1

Os requisitos estão de acordo com o que foi definido anteriormente para o Sistema de Agendamento para Barbearia.
