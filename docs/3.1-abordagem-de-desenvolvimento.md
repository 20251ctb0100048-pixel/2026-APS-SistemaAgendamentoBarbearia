# 3.1 Abordagem de Desenvolvimento

O desenvolvimento do sistema será realizado de forma iterativa e incremental, construindo o projeto por partes ao longo das aulas.

Primeiro serão definidos o problema, o objetivo, os usuários e o escopo do sistema. Depois serão desenvolvidos os requisitos, casos de uso, classes, diagramas, banco de dados e protótipos de interface.

A cada etapa, o que foi desenvolvido será revisado com base nas etapas anteriores, permitindo corrigir problemas e melhorar o projeto antes de avançar para a próxima parte.

Essa abordagem foi escolhida porque permite desenvolver o sistema da barbearia de forma organizada, verificando cada parte aos poucos e evitando que erros sejam descobertos somente no final do projeto.
