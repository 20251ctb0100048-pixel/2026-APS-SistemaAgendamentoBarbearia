# Sistema de Agendamento para Barbearia

Projeto Integrador de Análise e Projeto de Sistemas, 2026.
IFPR, Centro de Referência Ponta Grossa. Técnico em Informática Integrado ao Ensino Médio.

**Autoria:** Alcides Diniz Veiga

**Cliente:** João, meu vizinho, que trabalha em uma barbearia

## Apresentação do projeto

O Sistema de Agendamento para Barbearia será desenvolvido para ajudar no controle dos horários de atendimento, clientes, barbeiros e serviços oferecidos pela barbearia. O sistema busca facilitar a organização dos agendamentos e evitar conflitos de horários.
